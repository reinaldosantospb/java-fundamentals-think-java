<h2>📖 Chapter 3 – Input and Output</h2>

<h3>📚 Overview</h3>

<p>
This chapter introduces input and output in Java based on the
concepts presented in <i>Think Java (2nd Edition)</i>.
The exercises focus on reading data from the keyboard using
the <i>Scanner</i> class, processing user input, and displaying
formatted output using <i>System.out</i> and <i>printf</i>.
</p>

<h3>🎯 Learning Objectives</h3>

<ul>
  <li>Understand input and output in Java.</li>
  <li>Read data from the keyboard using the Scanner class.</li>
  <li>Use the System.in input stream.</li>
  <li>Import and use classes from the Java standard library.</li>
  <li>Read integer and floating-point values.</li>
  <li>Perform calculations using user input.</li>
  <li>Use integer division and the remainder operator (%).</li>
  <li>Format output using System.out.printf.</li>
  <li>Use format specifiers for displaying values.</li>
  <li>Build interactive console programs.</li>
</ul>
