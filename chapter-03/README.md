<h2>📖 Chapter 3 – Input and Output</h2>

<h3>📚 Overview</h3>

<p>
This chapter introduces input and output operations in Java.
It explains how programs communicate with users through the
console, display formatted output, and read user input using
the <code>Scanner</code> class. The exercises reinforce the
fundamental concepts required to build interactive Java programs.
</p>

<h3>🎯 Learning Objectives</h3>

<ul>
  <li>Understand the purpose of input and output.</li>
  <li>Display information using <code>System.out.print()</code> and <code>System.out.println()</code>.</li>
  <li>Format output using <code>System.out.printf()</code>.</li>
  <li>Read user input with the <code>Scanner</code> class.</li>
  <li>Store user input in variables.</li>
  <li>Convert and process different data types.</li>
  <li>Build simple interactive Java applications.</li>
</ul>
