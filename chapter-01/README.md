<h2>📖 Chapter 1 – Computer Programming</h2>

<h3>📚 Overview</h3>

<p>
This chapter introduces the fundamentals of computer programming and the
basic structure of a Java program. It explains how Java code is written,
compiled, and executed, while presenting the essential concepts required
to begin learning the language.
</p>

<h3>🎯 Learning Objectives</h3>

<ul>
  <li>Understand the purpose of computer programming.</li>
  <li>Learn the basic structure of a Java program.</li>
  <li>Understand the role of the <code>main()</code> method.</li>
  <li>Use <code>System.out.print()</code> and <code>System.out.println()</code>.</li>
  <li>Practice writing comments and formatted source code.</li>
  <li>Understand the Java compilation process and the JVM.</li>
</ul>
