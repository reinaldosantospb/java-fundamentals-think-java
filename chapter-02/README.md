<h2>📖 Chapter 2 – Variables and Operators</h2>

<h3>📚 Overview</h3>

<p>
This chapter introduces variables, primitive data types, arithmetic
operators, and expressions in Java based on the concepts presented in
<i>Think Java (2nd Edition)</i>. The exercises reinforce the fundamental
concepts required to write simple, readable, and efficient Java programs.
</p>

<h3>🎯 Learning Objectives</h3>

<ul>
  <li>Understand the purpose of variables.</li>
  <li>Learn Java primitive data types.</li>
  <li>Declare and initialize variables.</li>
  <li>Use arithmetic operators.</li>
  <li>Create and evaluate expressions.</li>
  <li>Perform calculations using variables and expressions.</li>
  <li>Follow Java naming conventions.</li>
</ul>
