## 📖 Chapter 4 – Methods

### 📚 Overview

This chapter introduces methods in Java based on the concepts presented in *Think Java (2nd Edition)*.

The exercises focus on defining and invoking methods, using parameters and arguments, understanding return values, and organizing programs into smaller and reusable components.

### 🎯 Learning Objectives

- Understand the purpose of methods in Java.
- Define and invoke methods.
- Understand method parameters and arguments.
- Pass values to methods using arguments.
- Use multiple parameters in a method.
- Understand the difference between parameters and arguments.
- Use return values from methods.
- Declare methods with different return types.
- Use `void` methods that do not return a value.
- Organize programs using reusable methods.
- Improve code readability and organization.
- Understand method invocation and execution flow.
